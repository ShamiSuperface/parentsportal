# פורטל הגיל הרך - parentsportal.org.il

מפות לגיל הרך לפי עיר. כל הערים רצות על אותו קוד בדיוק. ההבדל בין עיר לעיר הוא רק בשלושה בלוקים של JSON בתוך העמוד (`data`, `walk`, `city`) ובכמה מחרוזות קבועות בראש העמוד.

- `/` דף הבית ובחירת עיר
- `/ramat-gan/` רמת גן וגבעתיים
- `/rishon-lezion/` ראשון לציון
- `tools/make_share_images.py` יוצר את תמונות השיתוף (`share.jpg` בכל עיר ובשורש, 1200x630) ממפת העיר שבבלוק הנתונים. מריצים אחרי רענון נתונים או הוספת עיר, ומוסיפים את העיר לרשימה CITIES שבו.
- `tools/build_site.py` בונה את האתר מהקוד המשותף ומוסיף: חיוג ישיר, "המיקום שלי", ספירת שימוש אנונימית ושורת פרטיות.

ספירת השימוש נשמרת בסופאבייס (פרויקט parentsportal, טבלה events, הרשאת הוספה בלבד). לא נשמרים כתובות, מיקום, שמות או טלפונים. `?notrack=1` מוציא את הדפדפן מהספירה, ו-`?notrack=0` מחזיר.
